# 红楼梦模拟器

> 满纸荒唐言，一把辛酸泪。都云作者痴，谁解其中味？

一款基于曹雪芹《红楼梦》原著开发的**沉浸式文字冒险网页游戏**。玩家可选择不同身份进入大观园，体验原著剧情的不同走向，通过选择系统与属性系统创造高度个性化的游戏体验。

纯前端实现，无需后端，打开即玩。

## 游戏特色

- **11 位可选角色**：贾宝玉、林黛玉、薛宝钗、史湘云、贾母、贾探春、王熙凤、李纨、妙玉、晴雯、袭人
- **多路线分支剧情**：每位角色拥有 3 条专属命运线，选择决定结局走向
- **6 项核心属性**：智慧、魅力、才华、情感、福气、健康，实时影响剧情文本与可选项
- **人物关系系统**：0–100 关系值分档（陌生 / 相识 / 友好 / 亲密 / 知己），影响事件触发
- **原著经典场景**：共读西厢、黛玉葬花、宝玉挨打、抄检大观园、晴雯之死、黛玉焚稿、芦雪庵联诗、醉卧芍药裀、探春远嫁、贾府抄家等
- **结局收集图鉴**：自动记录已解锁结局，按角色分组展示，进度持久化保存
- **随机事件系统**：属性与关系达标时触发隐藏事件
- **存档 / 自动播放 / 对话记录**：完整游戏体验配套功能

## 玩法说明

### 操作方式

| 操作 | 方式 |
|------|------|
| 推进对话 | 点击对话区域 / 空格键 / 回车键 |
| 做出选择 | 点击选项按钮 |
| 打开菜单 | 左上角菜单按钮 / ESC 键 |
| 存档 | 右上角存档按钮 / Ctrl+S |
| 自动播放 | 右上角播放按钮 |
| 查看对话记录 | 右上角记录按钮 |

### 属性与关系

- 属性范围 **1–10**，不同选择会增减属性
- 关系值范围 **0–100**，达到阈值解锁特殊对话与选项
- 部分结局需要满足特定属性 / 关系 / 剧情标记（flag）条件

## 本地运行

无需安装任何依赖，直接双击 `index.html` 即可游玩。

若想用本地服务器（推荐，避免个别浏览器的 file 协议限制）：

```bash
# 方式一：Python
python -m http.server 8080

# 方式二：Node.js
npx serve .
```

然后浏览 `http://localhost:8080`。

## 部署到 GitHub Pages

本仓库已配置 GitHub Actions 自动部署：

1. 推送代码到 `main` 分支
2. 进入仓库 **Settings → Pages**
3. Source 选择 **GitHub Actions**
4. 等待 Actions 完成后，访问 `https://<用户名>.github.io/<仓库名>/`

也可以使用传统方式：**Settings → Pages → Deploy from a branch → main / (root)**。
