# 红楼梦模拟器 - 游戏说明文档

## 一、游戏简介

红楼梦模拟器是一款基于曹雪芹《红楼梦》原著开发的沉浸式文字冒险网页游戏。玩家可选择不同身份进入大观园，体验原著剧情的不同走向，通过精心设计的选择系统和随机事件创造高度个性化的游戏体验。

**版本：** 1.0.0
**技术栈：** HTML5 / CSS3 / 原生JavaScript
**运行方式：** 纯前端静态网页，无需后端服务，直接打开index.html即可运行

---

## 二、游戏玩法说明

### 2.1 开始游戏

1. 打开 `index.html` 文件启动游戏
2. 在主菜单点击"开始新游戏"
3. 从11位可选角色中选择一位作为主角
4. 查看角色背景故事、属性和人物关系后确认选择
5. 进入大观园，开始你的红楼梦之旅

### 2.2 游戏操作

| 操作 | 方式 |
|------|------|
| 推进对话 | 点击对话区域 / 按空格键 / 按回车键 |
| 做出选择 | 点击选项按钮 |
| 打开菜单 | 点击左上角菜单按钮 / 按ESC键 |
| 存档 | 点击右上角存档按钮 / Ctrl+S快速存档 |
| 自动播放 | 点击右上角播放按钮 |
| 查看对话记录 | 点击右上角记录按钮 |

### 2.3 角色属性系统

游戏包含6项核心属性：

- **智慧** - 影响决策洞察力和学识相关事件
- **魅力** - 影响社交互动和人际关系
- **才华** - 影响诗社活动和文学创作
- **情感** - 影响情感相关剧情和人物关系
- **福气** - 影响随机事件的结果和运势
- **健康** - 影响角色状态和部分剧情触发

属性范围：1-10，不同选择会影响属性增减。

### 2.4 人物关系系统

与每位角色的关系值范围为0-100：
- 0-20：陌生
- 21-40：相识
- 41-60：友好
- 61-80：亲密
- 81-100：知己

关系值会影响剧情走向、事件触发和可用选择。

### 2.5 剧情分支

游戏采用非线性叙事系统，每个选择都会影响后续剧情发展：
- 不同角色有不同的专属剧情线
- 关键选择点会导向不同的结局
- 部分选择需要满足特定条件才能出现

### 2.6 随机事件

游戏包含104种随机事件，分为4类：
- **人物互动事件** (30种) - 与各角色的日常互动
- **环境探索事件** (20种) - 大观园各处的探索发现
- **季节性事件** (20种) - 随四季变化的特殊事件
- **隐藏触发事件** (34种) - 需满足特定条件才能触发

### 2.7 成就系统

游戏包含35种成就，分为5类：
- **剧情成就** - 与主线剧情相关
- **角色成就** - 与属性成长相关
- **探索成就** - 与场景探索相关
- **社交成就** - 与人物关系相关
- **收集成就** - 与游戏统计相关

成就分为4个等级：铜、银、金、铂金

## 三、角色背景介绍

### 3.1 贾宝玉 - 怡红公子
荣国府贾政之次子，自幼衔玉而生。天性聪慧，却厌恶仕途经济，独钟情于女儿世界。深爱林黛玉之才情，又敬薛宝钗之端庄，内心常在二者之间挣扎。

### 3.2 林黛玉 - 潇湘妃子
扬州巡盐御史林如海之独女，才情绝世，诗才冠绝大观园。寄居外祖母家，心中常生凄凉。对宝玉一往情深，前世为绛珠仙草，今生以泪还恩。

### 3.3 薛宝钗 - 蘅芜君
皇商薛姨妈之女，博学多才，为人处世圆融通达。佩金锁，与宝玉通灵玉暗合"金玉良缘"之说。以理性克制情感，是封建礼教的忠实践行者。

### 3.4 史湘云 - 枕霞旧友
保龄侯史鼐之侄女，自幼父母双亡。天性豪爽豁达，心直口快，醉眠芍药裀更是千古美谈。才思敏捷，诗才与黛玉不相上下。

### 3.5 贾母 - 史太君
贾府辈分最高的老祖宗，虽已年迈，却精神矍铄。她是贾府真正的定海神针，最疼爱宝玉和黛玉。

### 3.6 贾探春 - 蕉下客
贾政与赵姨娘之女，虽为庶出，却志向高远，才干出众。精明能干，曾代凤姐理家，大刀阔斧地兴利除弊。

### 3.7 王熙凤 - 凤辣子
贾琏之妻，贾府实际的管家人。精明强干，杀伐决断，却也狠辣毒辣，最终"机关算尽太聪明"。

### 3.8 李纨 - 稻香老农
贾珠之遗孀，青春丧偶，心如死灰。将全部希望寄托在儿子贾兰身上，在诗社中担任社长。

### 3.9 妙玉 - 槛外人
苏州仕宦人家之女，带发修行。为人孤高自许，却又欲洁何曾洁，云空未必空，卡在槛里槛外之间。

### 3.10 晴雯 - 芙蓉仙子
贾宝玉房中四大丫鬟之首，心灵手巧，性格刚烈，心比天高。宁折不弯，至死不屈，如一朵不屈的芙蓉花。

### 3.11 袭人 - 贤袭人
贾宝玉房中四大丫鬟之一，温柔和顺，贤良淑德。是封建礼教的忠实践行者，一生都在为别人而活。

## 四、系统功能说明

### 4.1 存档系统
- 支持10个手动存档位
- 自动存档功能（每5个剧情节点自动保存）
- 存档包含：角色信息、剧情进度、属性、关系值、成就等
- 存档数据保存在浏览器LocalStorage中

### 4.2 设置系统
- 音乐音量调节（0-100）
- 音效音量调节（0-100）
- 文字显示速度（5档）
- 自动播放速度（5档）
- 文字大小（小/中/大）
- 全屏模式

### 4.3 对话记录
- 记录最近200条对话
- 按时间顺序排列
- 标注说话人

### 4.4 快捷操作
- 角色信息查看
- 人物关系图谱
- 物品栏
- 成就面板
